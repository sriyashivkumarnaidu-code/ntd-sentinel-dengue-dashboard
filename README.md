# NTD Sentinel Dengue Intelligence Dashboard

Static website package for GitHub Pages. The dashboard is preserved as `index.html`.

## Publish with GitHub Pages

1. Create a public GitHub repository for this project.
2. Upload `index.html` to the repository root and commit it to the default branch.
3. In repository Settings, open Pages and select deployment from the default branch and root folder.
4. After publication, open the provided site URL and test the dashboard controls.

The page loads fonts and map libraries from external CDNs, so those features require an internet connection.
